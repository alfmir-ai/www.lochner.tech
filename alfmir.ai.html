Alfmir.ai is an open-source, MIT-licensed AI software project focused on agentic coding workflows, project management, image design, and AI chat with embedded web search.

Open Beta includes limited access to open-model agents using Qwen Coder 30B A3B and Kwaipilot/KAT-Coder-V2.5-Dev, subject to capacity.

Both models can run on your own computer with an NVIDIA RTX 3090 or similar GPU.

The project is currently in demo / open beta form. Production accounts, billing, and full commercial infrastructure are not yet launched. There are currently no paid customers or active subscriptions.

Alfmir.ai is a SaaS product with free and paid tiers, while the core project remains open source and self-hostable. The SaaS platform is engineered to be privacy-first: your data is stored only on our bare-metal servers at Lochner Technology and is encrypted at rest using private credentials associated with your account, similar to Proton Mail's architecture, so not even Lochner Technology can access it. You can verify the architecture in the open-source code and verify the frontend code you are using with the IPFS verifier widget.

The website frontend is published to IPFS as a content-addressed release, making its files independently verifiable and retrievable through compatible gateways when providers retain a copy. Alfmir.ai's hosted application and backend services are not decentralized, and service access remains subject to applicable legal and regional restrictions.

Engineering work

Responsibilities include product strategy, full-stack development, cloud/DevOps, data pipelines, and integrations across AI APIs, project workflows, search, design tools, and commerce experiments.
